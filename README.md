# Installing Claude Code — Glide Slope AI

A 72-slide, one-idea-per-slide walkthrough for installing Claude Code. Single
self-contained `index.html`.

- Every command, requirement, error, and fix is sourced from Anthropic's official
  docs at code.claude.com/docs (see the final slide for the specific pages).
- Covers both paths: the Desktop app and the Terminal CLI.
- Includes the PATH failure — the #1 reason beginners quit — shown then fixed.
- Ten of the visuals are real captures, not mockups. See `review.html` for provenance.

Navigation: arrow keys / space, swipe on mobile, `O` for the slide overview,
`⌂ Start` or Home to return to slide 1, deep-linkable via `#<slide-number>`.
